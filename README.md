# Suryaprakash Boda — 3D Interactive Portfolio

Professional 3D portfolio built with React, Three.js, and Tailwind CSS.

## Tech Stack
- React 19 + TypeScript
- Vite (build tool)
- Three.js + React Three Fiber (3D)
- React Three Drei (3D helpers)
- Tailwind CSS + custom 3D styling
- React Scroll Parallax (animations)

## Run Locally
```bash
npm install
npm run dev
npm run build
```

## Sections
1. **Hero** — 3D rotating cube with name and tagline
2. **About** — Glass-morphism card with bio
3. **Skills** — Interactive 3D torus with skill tags
4. **Projects** — Card grid with live links
5. **Contact** — Form with 3D background
